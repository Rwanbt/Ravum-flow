CAVEAT THAT MATTERS FOR THE NEXT MEASUREMENT (MEASURED, see FLOW-QUALITY-WAVE3.md)
  `--ignore-filename-regex '[\\/]tests[\\/]'` does not only exclude test sources: a source
  module imported into an integration test with `#[path = "../src/x.rs"]` is recorded with
  the filename `crates\flow\tests\..\src\x.rs`, which this regex also excludes. All
  coverage exercised by `tests/isolation.rs` through the imported `scratch.rs`, and by
  `tests/bounds.rs` through the imported `gitcli.rs`, is therefore invisible above.
  `scratch.rs`'s real exercised coverage is higher than the 71.04 % shown; the filtered
  number is the one the gate uses, so it is the one kept as the baseline.

  A second, independent hygiene fact: `cargo-llvm-cov report` merges every `*.profraw`
  present in the target directory, and those files accumulate across runs (measured
  455 → 769 after one extra run). Measurements must start with
  `cargo +nightly llvm-cov clean --workspace` (or a fresh CARGO_TARGET_DIR); this file's
  numbers were produced in a fresh directory.
