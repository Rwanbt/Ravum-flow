WHY scratch.rs CANNOT HONESTLY REACH 85 % UNDER THIS COMMAND (MEASURED)
  The ignore filter drops coverage of every source module imported into an integration test
  via `#[path = "../src/x.rs"]`: the profile records such code as
  `crates\flow\tests\..\src\scratch.rs`, which `[\\/]tests[\\/]` excludes. `tests/isolation.rs`
  imports `scratch.rs` directly and exercises `materialise_in`, `verify_created_dir`,
  `detach_git_link` and `Drop` refusals there; none of it reaches the number above. Through
  the shipped binary only the paths reachable from `flow run` count (a host temp directory
  redirected into the repository, a hook that removes the checkout's `.git` link), and those
  are covered by this wave. The remaining 67 uncovered lines are enumerated in
  docs/reviews/FLOW-QUALITY-WAVE3.md §3; most are only reachable by calling the module
  directly, which the prescribed metric cannot see.
