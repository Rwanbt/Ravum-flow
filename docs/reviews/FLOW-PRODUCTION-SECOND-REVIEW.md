## 5. What I verified as sound (with the checks that prove it)
- **Zero dependencies.** `crates/flow/Cargo.toml` has an empty `[dependencies]`; `Cargo.lock` contains exactly one package (`flow 0.2.0-rc.1`, lockfile version 4) and is tracked by Git; workspace `Cargo.toml` has no dependency. `cargo build --locked` is therefore meaningful.
- **No build script, no unsafe, no network.** `Get-ChildItem -Recurse -Filter build.rs` → none; a content search over `crates/flow` found no `unsafe` block (only the word in a comment `gitcli.rs:659`); no `TcpStream`/`http(s)://`/`curl`/`wget` in `src/`.
- **The CI gates are real.** I extracted all **62** names from the `for gate in …` list and confirmed each has a matching `fn` in `crates/flow/{src,tests}` — including the five module-qualified `lock::tests::*` / `paths::tests::*` added while I reviewed. A typo would have made the job un-green, so the gate list is not decorative.
- **CAS ordering is as documented.** `cmd_publish` reads the ref, appends intent, re-reads, `update-ref <new> <old>`, reads back, and only then records `PUBLISHED` (`commands.rs:1687-1753`); `reconcile` observes without moving a ref (`:1920-2049`) and refuses duplicates (`:1950-1960`).
- **Journal reads fail closed.** Missing file = empty; unreadable = `JournalError::Io`; a torn line = `Corrupt` (`state.rs:404-424`), and `status` propagates it instead of reporting 0 pending (`commands.rs:593`).
- **Writes below `.flow/` are link-guarded.** `guard_below_flow` rejects symlinks, Windows reparse points and (Unix) `nlink > 1` (`state.rs:287-345`), and is called from every `write_atomic*`/`append_journal` path.
- **The release crash hook is compiled out.** `crash_point` returns false when `!cfg!(debug_assertions)` (`commands.rs:1840-1845`), and CI proves it on the release binary (`flow-ci.yml:218-256`); the new install smoke also checks that the install directory gains no files (`:208-211`).
- **Env scrubbing is genuinely broad.** `SCRUBBED_GIT_ENV` (`gitcli.rs:235-261`) covers the documented redirects plus `GIT_CONFIG_KEY_*/VALUE_*` by prefix; `GIT_TERMINAL_PROMPT=0`, `GIT_PAGER=cat`, `GIT_CONFIG_NOSYSTEM=1` are forced (`:338-343`).
- **Bounds are enforced, not aspirational.** Git output is refused (not truncated) past 64 MiB (`gitcli.rs:142-151,417`), obligations are capped at 1 MiB with a drain (`:388,427-450`), and both have tests named in the gate list.
- **The commit graph matches the review brief.** `git diff --stat feat/flow-mvp-0.1..HEAD -- crates/flow/src` is 624 insertions / 52 deletions over eight files (`commands.rs` 266, `lock.rs` 131, `paths.rs` 120, `state.rs` 58, `gitcli.rs` 54, `json.rs` 27, `main.rs` 10, `proposal.rs` 10), while the bulk of the 343-file diff is docs and `experiments/**` evidence; `crates/flow/Cargo.toml` is `0.2.0-rc.1`.
- **Refusals in the publish path are specific, not generic.** Schema, integrity, tree, scope, missing-required, policy digest, policy version, boundary, context, per-obligation status, commit-tree, staleness, already-published and base mismatch each have their own code (`commands.rs:1413-1596`).
